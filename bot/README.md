# League Hub Discord Bot

This is a ready-to-run Discord.js v14 bot that talks to the League Hub API using the bot API key.

Commands:

- `/league standings`
- `/team add name short_name tag logo_url description`
- `/team remove team_id`
- `/fixture add home_team_id away_team_id date venue round`
- `/result add match_id home_score away_score`
- `/news post title excerpt body category image_url`

Run `npm install`, fill `.env`, run `npm run register`, then `npm start`.
